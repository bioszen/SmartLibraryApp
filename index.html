Smart Library Control Center

Guía Avanzada - BSZ Edition

Smart Library es tu asistente inteligente para la gestión de comandos. Diseñado para quienes necesitan usar fragmentos de código repetitivos pero con variaciones mínimas (rutas, nombres, parámetros), transformando scripts estáticos en herramientas dinámicas.

Privacidad Garantizada: Tus comandos y snippets se almacenan exclusivamente de manera local en tu navegador (LocalStorage). Smart Library solo actúa como una interfaz para leer, organizar y facilitar su uso. Ningún dato es enviado a servidores externos.

Ingreso

🚀 Métodos de Carga Inteligente

No pierdas tiempo gestionando archivos de uno en uno:

  • Arrastrar y Soltar: Suelta múltiples scripts (.R, .py, .sh, etc.) o archivos ZIP. El sistema procesará todo en una cola automatizada.
  • Cloud Import: Pega enlaces de GitHub, Gist, Dropbox, Google Drive o OneDrive. El sistema usará proxies inteligentes para saltar bloqueos de red y traer el código directo a tu biblioteca.
  • Carga en Lote: Si subes varios archivos, verás una cola de procesamiento que te permite revisar uno a uno antes de agregarlos definitivamente.
Interactividad

⚡ Variables Dinámicas {{...}}

Convierte código estático en formularios interactivos. Ideal para evitar errores al modificar scripts:

# En lugar de:
input <- read.csv("C:/datos/exp1.csv")

# Usa:
input <- read.csv("{{Archivo_Entrada}}")

Al abrir el comando, el sistema generará un campo de texto automáticamente. Al llenarlo, el código se actualiza en tiempo real listo para ser copiado o descargado.

Editor

📝 Monaco Editor Profesional

La edición de comandos utiliza la misma tecnología que VS Code. Disfruta de resaltado de sintaxis, números de línea y una interfaz de edición fluida para R, Python, PowerShell y más.

Inteligencia

🔍 Validación y Versiones

  • Corrector de Slashes: Detecta si has mezclado '/' y '\' en tus rutas de archivos y ofrece corregirlas automáticamente según el estándar de tu sistema.
  • Control de Versiones: Si guardas un script similar a uno existente, el sistema crea una Versión 2. Esto mantiene tu biblioteca organizada y te permite comparar mejoras de un mismo comando.
  • Validación de Sintaxis: Avisos instantáneos si detecta paréntesis o llaves sin cerrar antes de guardar.
Gestión

📁 Organización Masiva

Utiliza el Modo Selección para marcar múltiples comandos. Podrás moverlos a colecciones específicas, eliminar duplicados o realizar una limpieza global de categorías (Tags) desde el gestor avanzado.

🎓 Ventajas para Principiantes

Smart Library elimina la fricción de "romper el código" por error:

1. Evita el "Copy-Paste" peligroso: No manipules el código fuente directamente, solo rellena las variables.
2. Centralización: Tu conocimiento de años en un solo archivo portable.
3. Seguridad: El sistema actúa como un filtro contra errores tipográficos comunes en rutas y sintaxis.

Smart Library is your intelligent command management assistant. Designed for those who need to use repetitive code fragments with minimal variations (paths, names, parameters), transforming static scripts into dynamic tools.

Ingestion

🚀 Intelligent Loading Methods

Don't waste time managing files one by one:

  • Drag & Drop: Drop multiple scripts (.R, .py, .sh, etc.) or ZIP files. The system will process everything in an automated queue.
  • Cloud Import: Paste links from GitHub, Gist, Dropbox, Google Drive, or OneDrive. The system will use smart proxies to bypass network blocks and bring the code directly to your library.
  • Batch Loading: If you upload several files, you'll see a processing queue that lets you review each one before adding them permanently.
Interactivity

⚡ Dynamic Variables {{...}}

Convert static code into interactive forms. Perfect for avoiding errors when modifying scripts:

# Instead of:
input <- read.csv("C:/data/exp1.csv")

# Use:
input <- read.csv("{{Input_File}}")

When opening the command, the system will automatically generate a text field. As you fill it in, the code updates in real-time ready to be copied or downloaded.

Editor

📝 Professional Monaco Editor

Command editing uses the same technology as VS Code. Enjoy syntax highlighting, line numbers, and a smooth editing interface for R, Python, PowerShell, and more.

Intelligence

🔍 Validation and Versions

  • Slash Corrector: Detects if you've mixed '/' and '\' in your file paths and offers to fix them automatically based on your system standard.
  • Version Control: If you save a script similar to an existing one, the system creates a Version 2. This keeps your library organized and lets you compare improvements to the same command.
  • Syntax Validation: Instant warnings if it detects unclosed parentheses or braces before saving.
Management

📁 Massive Organization

Use Selection Mode to mark multiple commands. You can move them to specific collections, delete duplicates, or perform a global category (Tag) cleanup from the advanced manager.

🎓 Advantages for Beginners

1. Avoid dangerous "Copy-Paste": Don't manipulate the source code directly, just fill in the variables.
